# V550 自定义 Gazebo 场地与轨迹显示

你选择的是“空旷场地，自己摆障碍物”。已增加一个 **12 m × 10 m 的空场地**，
只有地板和四周边界墙，中央起点是 `(0, 0)`，使用厂家 V550_mec 模型和单线二维雷达。

后续增加的 24 × 18 米六房间场地、门扇、蓝色激光显示，以及撞障问题的进一步修正见
[V550 大型室内仿真](V550室内仿真.md)。下文 5.13 m 绕障记录对应较早配置，不能说明任意布局不会碰撞。

## 1. 启动空场地

先关闭自己之前启动的同一套仿真，避免同时占用同一个 Gazebo 端口。在新终端执行：

```bash
cd ~/ego_ground_ws
source /opt/ros/humble/setup.bash
source install/local_setup.bash
export ROS_DOMAIN_ID=218 ROS_LOCALHOST_ONLY=1
export GAZEBO_MASTER_URI=http://127.0.0.1:11358
ros2 launch ego_ground_sim sim_v550_custom.launch.py
```

Gazebo 默认从上往下俯视，RViz 也默认俯视。先在 RViz 用 **2D Goal Pose** 选一个近处空地。
空地上规划出直线是正常的；想验证绕障，需要先把障碍放在起点与目标之间。

## 2. 在 Gazebo 中自己摆障碍物

以下操作都在 **Gazebo 窗口**里，不是在 RViz 里。

1. 先让小车停下，再点击底部暂停按钮，避免布置场地时小车继续行驶。
2. 点击顶部工具栏的 **Box（方块）** 或 **Cylinder（圆柱）** 图标，再在地板上点击放置。
   最开始可以直接使用默认 1 m 方块。
3. 点击选中障碍物，用工具栏的平移、旋转工具调整位置。也可以在左侧 World → Models
   选中模型，展开 `pose` 调整数值。不要移动 `v550_mec` 或地板。
4. 如果创建的是动态物体，它会受重力和碰撞影响；用于固定墙体的模型应设置为静态。
   若在界面中不方便修改，可以保存后在对应 `<model>` 内设置 `<static>true</static>`。
5. 障碍物应落在地板上，且具有碰撞形状。当前激光扫描高度约为离地 **0.11 m**，
   障碍物必须穿过这个高度才能被单线雷达看到。悬空障碍、太低的障碍不能靠这个雷达可靠识别。
6. 解除暂停，等 RViz 中出现障碍物，再点选目标。先留足通道宽度，避免把小车完全围住。

蓝色区域是膨胀后的障碍区域，规划曲线应绕开它。摆放障碍并不会让 RViz 直接读取 Gazebo 模型：
它仍然需要经过“模拟雷达扫描 → 障碍点 → 局部地图”这条链路。

Gazebo 的建场地和保存功能可参考 [Gazebo 官方教程](https://classic.gazebosim.org/tutorials?cat=build_world&tut=build_world)。

## 3. 保存并重新加载自己的地图

在 Gazebo 菜单选择 **File → Save World As**，保存为绝对路径，例如：

```text
/home/zoujing/ego_ground_ws/my_maps/lab.world
```

先在文件管理器中创建 `my_maps` 文件夹，或者执行：

```bash
mkdir -p ~/ego_ground_ws/my_maps
```

Gazebo 保存的是三维场景文件 `.world`，包含地面、模型位置、几何形状等。
它和导航常见的 `.pgm + .yaml` 二维占据栅格地图不是同一种文件。

结束当前启动命令后，用自己的文件重新启动：

```bash
ros2 launch ego_ground_sim sim_v550_custom.launch.py \
  world:=/home/zoujing/ego_ground_ws/my_maps/lab.world
```

如果保存时场景里有 V550，启动入口会在临时副本中去掉已保存的 `v550_mec`，
然后按启动参数重新生成小车，原始 `.world` 文件保持原样。
这可以避免保存后的地图再次启动时出现“v550_mec 已经存在”。
模型名请保留为 `v550_mec`，不要另存一份改名的小车模型。
从外部导入的 mesh、纹理仍需随地图保留，并使用可解析的绝对 `file://` 或 `model://` 路径。

换起点也可以通过参数设置，例如让小车从左边向右行驶：

```bash
ros2 launch ego_ground_sim sim_v550_custom.launch.py \
  world:=/home/zoujing/ego_ground_ws/my_maps/lab.world \
  spawn_x:=-3.0 spawn_y:=0.0 spawn_yaw:=0.0
```

起点要有地板支撑，不能在障碍物里。地图修改后建议重启仿真，重新建立局部障碍地图。

也可以直接在加载过相同环境的终端保存当前场景：

```bash
python3 install/ego_ground_sim/share/ego_ground_sim/scripts/save_v550_world.py \
  ~/ego_ground_ws/my_maps/lab.world
```

这会保留已经摆放的模型、删除保存文件里的 V550 副本。命令通过 `GAZEBO_MASTER_URI` 连接当前 Gazebo。
本次调试时已把你摆放的布局保存为 `my_maps/v550_current_scene.world`。

## 4. 看哪条线才能判断是否在跟踪 EGO-Planner

| RViz 显示项 | 颜色 | 含义 |
| --- | --- | --- |
| `EGO planned curve (green)` | 绿色 | 从 `/planning/bspline` 实际采样出的平滑曲线，与 MPC 接收的是同一条轨迹 |
| `Actual driven path (orange)` | 橙色 | 根据 `/odom_combined` 记录的小车实际行驶轨迹 |
| `Spline control polygon (not driven path)` | 红色，默认关闭 | 控制点之间的连线，车不需要逐个经过这些点 |
| `Global reference (not obstacle avoidance)` | 青色，默认关闭 | 全局参考，不是经过局部避障优化后交给 MPC 的最终曲线 |

新目标会清空上一段实际轨迹。EGO 会连续重规划，所以绿色线表示**最新的一段局部轨迹**，
橙色线表示本次目标开始后已经走过的路径；二者不会始终完整重叠。
到达后，最后一段绿色线会保留，便于观察；RViz 后打开也能收到它。
显示用的曲线略微抬高，以免被地面地图遮住，不会改变规划和控制使用的坐标。

原先看起来不一致有两个原因：原来的红线是控制点折线；MPC 的代价又把输入向零压低，
没有把参考速度和转向角速度作为输入代价的基准，会造成滞后。
现在改为围绕轨迹参考输入优化，并让预测状态对应下一时刻；偏航角也会连续展开，避免跨越 ±π 时跳变。
V550 仿真还把预测时长从 0.45 s 增加到 1.2 s，提高位置误差权重，
将起步朝向容差从 25° 收紧到约 4.6°。这些新增配置的默认值保持其他入口原来的设置。
仿真 `/clock` 也改为 100 Hz，避免 10 Hz 时钟让雷达时间戳暂时领先并被新鲜度检查丢弃。

## 5. 调整“上帝视角”

俯视高度越大，看到的范围越大。默认空场地高度为 12 m，例如改为 16 m：

```bash
ros2 launch ego_ground_sim sim_v550_custom.launch.py camera_height:=16.0
```

俯视相机固定在初始位置上方，便于布置和观察整个区域；鼠标操作后可以重新定位：

```bash
python3 install/ego_ground_sim/share/ego_ground_sim/scripts/focus_v550.py \
  --view top --height 12 --center-x 0 --center-y 0
```

该命令需要相同的 `GAZEBO_MASTER_URI`。如果想恢复原来的跟随视角：

```bash
python3 install/ego_ground_sim/share/ego_ground_sim/scripts/focus_v550.py --view follow
```

仍可启动原来的 CMU 室内地图：

```bash
ros2 launch ego_ground_sim sim_v550_mec_2d.launch.py
```

文件入口：[空场地](ego_ground_sim/worlds/v550_empty.world)、
[自定义地图启动文件](ego_ground_sim/launch/sim_v550_custom.launch.py)、
[轨迹显示节点](ego_ground_sim/src/trajectory_visualizer.cpp)。
这些改动用于仿真验证；麦轮仍使用理想平面运动，实车跟踪需要单独测试。

2026-10-15 的独立绕障检查已通过：4 m 的直线起终点距离实际绕行约 5.13 m，
停车误差约 2.3 cm；与当时有效局部曲线的距离均方根约 13 cm，最大约 37 cm，
结束速度为零。详细复现命令和报告见 [V550 仿真](V550仿真.md)。

如果另一个终端提示 `Failed to find a free participant index`，
在那个终端加载本次提供的 Cyclone DDS 仿真配置后再执行 ROS 命令：

```bash
export CYCLONEDDS_URI=file://$HOME/ego_ground_ws/install/ego_ground_sim/share/ego_ground_sim/config/cyclonedds_sim.xml
```
